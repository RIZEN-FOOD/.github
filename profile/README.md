# 라이즌푸드 (RIZEN FOOD)

크림오브라이스 — 곱게 도정한 쌀로 만든 탄수화물 보충 식품.

공식 웹사이트와 관리자 시스템을 만듭니다.

## 지켜야 할 것

**식품 표시·광고 규제** — 크림오브라이스는 일반 식품이지 건강기능식품이 아닙니다.
효능·효과를 표현하면 식품표시광고법 위반입니다. 카피를 새로 쓸 때마다 검토합니다.

**법정 표시사항은 텍스트로** — 영양성분·원재료·소비기한을 이미지에 넣지 않습니다.
이미지 속 글자는 검색에 안 잡히고 접근성에도 불리합니다.

**전자상거래법** — 통신판매업 신고번호와 사업자정보를 게시하고, 청약철회를 안내하며,
취소·반품·교환 이력을 보존합니다.

법적 책임 주체는 사업자(라이즌푸드)입니다.
